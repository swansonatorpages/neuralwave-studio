# NeuralWave Studio (PWA)

Self-contained offline Progressive Web App for stereo binaural beats, generative focus music, local audio overlay, and ambient noise masking.

## Quick GitHub Pages Deployment
1. Create a new repository on GitHub (e.g., `neuralwave-studio`).
2. Upload all 6 files (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`) to the root of the `main` branch.
3. Go to **Settings -> Pages**, set **Source** to **Deploy from a branch**, select `main` / `/ (root)`, and click **Save**.
4. Open `https://<your-username>.github.io/neuralwave-studio/` on your phone or desktop and tap **Add to Home Screen** or **Install App**.
